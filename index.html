Questions, answered

Does ButtLocker have a backdoor?

Absolutely not. The backdoor was the first thing we encrypted. Security researchers keep asking to inspect it, and the answer is still no.

What is rear-end encryption?

It's like end-to-end encryption, except we only protect the one end that really matters.

Does it work alongside Windows Defender?

Perfectly. Defender guards the front, ButtLocker guards the rear. Together you get full coverage.

Is Secure Booty on by default?

Yes. Unsigned cheeks won't load at startup, and anything suspicious is quarantined before it can sit down.

Can I unlock it with Windows Hello?

Windows Hello only recognizes faces. Please stop pointing the webcam where it doesn't belong.

Can IT access my butt remotely?

Remote Desktop requests to your posterior are denied by policy. IT can open a ticket like everyone else.

Does the firewall block everything?

All inbound traffic is blocked. Outbound traffic is still allowed, which explains what happened on that Teams call.

Why did my butt restart without warning?

It's Patch Tuesday. Updates always install at the worst possible moment. Save your work and clench.

What happens if I press Ctrl+Alt+Delete?

Task Manager opens and lists butt.exe as not responding. Ending the task is not recommended.

Absolutely not. The backdoor was the first thing we encrypted. Security researchers keep asking to inspect it, and the answer is still no.

It's like end-to-end encryption, except we only protect the one end that really matters.

Perfectly. Defender guards the front, ButtLocker guards the rear. Together you get full coverage.

Yes. Unsigned cheeks won't load at startup, and anything suspicious is quarantined before it can sit down.
